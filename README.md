# SoftUni Programming Fundamentals with C#

Solutions for the SoftUni Programming Fundamentals with C# course: basic syntax, data types, arrays, methods, lists,
objects and classes, associative arrays, text processing and regular expressions. One console project (`ExNNN`) per
problem; every lecture folder is its own solution with tests.
